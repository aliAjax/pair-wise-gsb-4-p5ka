# License Lens · SPDX 策略裁决台

纯前端开源依赖许可证裁决工具（React + Vite，无额外依赖）。

## 功能

- **导入依赖清单**：支持 `名称@版本 SPDX表达式` 行格式、CSV、`package.json`、JSON 数组，或手动添加。
- **SPDX 表达式解析**：支持 `AND` / `OR` / `WITH` / 括号 / `+` 后缀，未知标识、语法错误均定位到子表达式。
- **按分发方式裁决**：内部使用 / SaaS / 二进制分发 / 源码分发四种模型下，给出 允许 / 附条件 / 禁止 结论。
- **整批待复核**：未知标识、冲突组合（如 `GPL-2.0-only AND Apache-2.0`）、附条件义务缺证据时，整批停在待复核，并可定位到具体依赖与子表达式。
- **导出门禁**：只有整条表达式被放行，或经人工授权覆盖并填写依据，才允许导出 Markdown 报告。
- **版本链**：已裁决依赖再次导入只生成带原因的新版本，历史裁决不可改写。
- **本地持久化**：清单、证据、人工授权与版本链存于 localStorage，刷新后一致。

## 业务模块

| 模块 | 职责 |
| --- | --- |
| `src/lib/spdx.ts` | SPDX 表达式词法 / 语法解析、已知许可证与异常表、标识符校验（带位置信息） |
| `src/lib/policy.ts` | 分发方式 × 许可证类别策略矩阵、义务目录、冲突规则、表达式求值 |
| `src/lib/store.ts` | 工作区状态与版本链、localStorage 读写、导入、裁决编排、报告生成 |
