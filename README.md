# License Lens · SPDX 策略裁决台

按项目分发方式对依赖的 SPDX 许可证表达式逐条裁决的纯前端工具。React + Vite 实现，无新增依赖，数据仅存于浏览器 `localStorage`。

## 启动

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 产物构建
npm run preview  # 预览构建产物
```

## 业务规则

- **解析**：导入清单后，按 SPDX v2.3 附录四语法（括号、`AND`/`OR`/`WITH`、`+`）递归下降解析每个表达式；语法错误、未知许可证/例外标识不猜测，直接进入待复核。
- **策略判断**：依据项目分发方式（闭源分发 / 开源分发 / 云端 SaaS / 内部使用）对每个**子表达式**给出允许、附条件、禁止、待复核；`AND` 检测 copyleft × 专有等冲突组合，`OR` 自动选定当前分发方式下最宽松的合规路径（未选分支不阻断）。
- **整批闸门**：出现未知标识、冲突组合、禁止子句，或附条件义务（提供源码、声明修改、网络源码、商业授权等）缺少履行证据时，整批停在待复核，阻断点精确定位到依赖与子表达式（字符 span 高亮）。
- **放行路径**：只有整条表达式放行，或对该版本填写「授权人 + 依据」的人工授权覆盖后才计入放行；二者全部满足才解锁 Markdown 报告导出。
- **版本链**：已裁决依赖再次导入时，仅当版本或 SPDX 表达式变化才生成带原因的新版本（证据与授权不自动继承）；完全一致则只提示不建版。刷新页面后清单、证据、授权与版本链保持一致。

## 模块边界

业务逻辑与 React/持久化解耦，全部位于 `src/spdx/`：

| 模块 | 职责 |
|---|---|
| `parser.ts` | SPDX 表达式词法/语法分析，产出带 span 的语法树与解析问题 |
| `policy.ts` | 许可证登记表、义务定义、按分发方式裁决语法树 |
| `importer.ts` | 清单文本解析（逐行格式 / package.json）与版本链导入计划 |
| `adjudication.ts` | 证据核验、人工授权、整批阻断定位、导出闸门与报告生成 |
| `storage.ts` | `localStorage` 读写、校验、订阅（external store），不包含策略 |
| `types.ts` | 跨模块领域模型 |

界面层 `src/App.tsx` 与 `src/components/` 只负责编排与展示。
